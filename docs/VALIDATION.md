# Validation and scope

Minecraft 26.3, release 1.0.0-beta.1+26.3: Loka Fabric has 55 top-level mod jars; Loka Fabric+ has 82 and contains every base mod. Indexed client files are required in both editions. Release archive integrity and SHA-512 hashes are checked, as are shared-file equality and launch defaults.

Earlier in-game checks covered startup, title/pause layouts at normal and wide sizes, terrain loading in a local world and on Loka, multiplayer buttons, Voxy/Voxy Extra and shader rendering. The latest Loka UI build compiles successfully and passes affiliation/privacy regression checks. Its new Discord affiliation feature has not yet received an in-game Discord card check. A sustained PvP session and recording/export are outside this pass. Both title screenshots are native 1920×1080 captures without window chrome; the expanded screenshot was refreshed to avoid a video transition.

No launcher accounts, saved worlds, player logs, caches or machine-specific build directories are included.
