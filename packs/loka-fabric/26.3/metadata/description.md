# Loka Fabric

**The official Fabric modpack for Loka.**

Loka Fabric is a lightweight modpack built for playing on Loka. It combines performance optimizations, useful client-side mods, and a customized Loka experience in one ready-to-play package.

This is the official starting point for playing on Loka, with useful tools and ready-to-use settings.

## Included Mods

**Performance:** Sodium, Lithium, FerriteCore, ImmediatelyFast, EntityCulling, AntiStutter

**Utility:** Loka Atlas, Litematica, MiniHUD, Zoomify, AppleSkin, Shulker Box Tooltip, Gamma Utils, Uku's Armor HUD

**Resource pack:** JermsyBoy's Vanilla Edits

Loka Fabric also includes a custom Loka main menu, loading screen, and preconfigured server entry.

JermsyBoy's Vanilla Edits is installed for you to enable if you want it. MiniHUD starts off by default. Shaders, connected textures and distant-terrain rendering are included in Loka Fabric+.
