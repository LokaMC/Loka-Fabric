# Loka Fabric+

**The official expanded Fabric modpack for Loka.**

Loka Fabric+ builds on [Loka Fabric](https://modrinth.com/project/loka-fabric), adding more building tools, visual enhancements, animations, and immersive audio while retaining the same performance optimizations and essential client-side utilities.

Loka Fabric+ includes everything in Loka Fabric, along with additional mods for players looking for a more complete Minecraft experience.

## Additional Mods

**Building:** Axiom, WorldEdit, WorldEdit CUI, dbtools

**Replays & Cameras:** Flashback, Flashback Extras, Camera Utils

**Textures, Shaders & Terrain:** Continuity, Iris, Bobby, Voxy, Voxy Extra, Complementary Reimagined, Complementary Unbound, Euphoria Patches

**Visuals:** Better Clouds, LambDynamicLights, Falling Leaves

**Animations:** 3D Skin Layers, WaveyCapes

**Audio:** AmbientSounds, Presence Footsteps, Sound Physics Remastered

**Utility:** NBT Display, Simple World Downloader

Loka Fabric+ also includes Loka Fabric's custom Loka main menu, loading screen, resource pack, and preconfigured server entry.

The shared settings match Loka Fabric: JermsyBoy's pack is installed but unselected, shaders and MiniHUD start off, and GUI scale uses Auto.

All included mods must be used in accordance with our [client-side mod rules](https://forums.lokamc.com/threads/approved-legal-client-side-mods.4845/).
