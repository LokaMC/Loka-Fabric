# Asset and dependency licenses

The repository LICENSE covers original Loka UI code and pack maintenance code. Third-party mods, shaders, resource packs and artwork retain their own licenses; bundling does not relicense them. The `.mrpack` indexes retain official download URLs and file hashes. Loka Atlas, the local Voxy/Voxy Extra builds and supplied Loka artwork are included as approved by the pack owner. Large embedded dependencies are preserved in the shared-assets release archive. JermsyBoy Vanilla Edits remains the unmodified Modrinth download and is installed, not selected by default.
